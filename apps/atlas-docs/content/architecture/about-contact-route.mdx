---

## Contact delivery

Smallest Nexus production pattern:

1. **Resend** (`resend` package) — same provider as `iw-portal` / `iw-site-q2`
2. **Zod** server validation (`name`, `email`, `message`)
3. **Honeypot** field `company` (silent success when filled)
4. **In-memory rate limit** — 5 / IP / hour (`checkRateLimit`, same idea as `iw-site-q2/lib/kickoffRateLimit.ts`)
5. Env (server-only): `RESEND_API_KEY`, `CONTACT_EMAIL`, optional `RESEND_FROM`
6. E2E / local without Resend: `CONTACT_INSECURE_SKIP_SEND=true`

Rejected for Atlas: HubSpot, n8n, reCAPTCHA Enterprise, multi-step questionnaires.

| Item | Figma | Implementation | Why |
| --- | --- | --- | --- |
| Muted captions / meta | `#8A847A` | `atlas-body` | Known AA issue — do not silently retoken |

| Approach / boundary figure chrome | decorative dots / muted captions | sage dots; body-colored captions | AA |
| Tablet/mobile About | condensed sections | Style / Reading / Architecture / full Notes desktop-only; focus merges condensed personal note | Match Figma recomposition |
