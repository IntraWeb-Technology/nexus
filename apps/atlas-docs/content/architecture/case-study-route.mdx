## Accessibility report

**Target:** WCAG AA  
**Automated:** `@axe-core/playwright` — no serious/critical on `/work/portfolio-os`

Implemented:

- Semantic article nested in `main` landmark; one H1; logical H2/H3
- TOC as `nav` with accessible name
- Figures with `role="img"` + `aria-label` + `figcaption`
- `EditorialTable` as labeled row pairs (stack associations on narrow)
- Reading progress as `progressbar`
- Skip link + focusable `#main`
- Route-aware Work `aria-current`

### Design issues (documented — not redesigned)

1. **Muted token AA** — unchanged. Captions/meta prefer `atlas-body` / `atlas-secondary`.
2. **Ink-plane mono labels** — Figma uses muted on ink. Implementation uses `atlas-secondary` on ink so axe AA passes (decorative labels remain `aria-hidden`).
3. **CONTACT chapter on ink** — umber fails on ink; uses `atlas-secondary` (Home/Work precedent).

## Responsive observations

- Desktop carries full editorial density (3-col overview, decision matrix, table rows, 2-col implementation grid).
- Tablet collapses tables/matrices to prose summaries; architecture becomes two wrap rows; TOC becomes a single wrapped line.
- Mobile stacks TOC, architecture nodes, and condensed titles; hero/implementation reduce to single figures.
- Long-form reading width remains `~720px` (`--atlas-reading`) on problem/overview prose.

---

## Lessons learned

1. **Publishing primitives earn extraction when the template names them** — MetadataRow / EditorialTable / TOC / ReadingProgress are Manifest components, not speculative abstractions.
2. **Do not force unused publishing components** — CodeBlock/Callout/PullQuote stay deferred until a template requires them.
3. **Responsive case study is recomposition, not stacked desktop** — fixture stores condensed copy per breakpoint.
4. **Ink decorative labels need AA-safe tokens** even when `aria-hidden` — axe still evaluates contrast.
5. **ContactBridge remains page-local** — third consumer still does not share an identical shell.
