## Accessibility report

**Target:** WCAG AA  
**Automated:** `@axe-core/playwright` — no serious/critical on `/`

Implemented:

- Semantic landmarks and heading hierarchy
- Skip link + focusable main landmark (`tabIndex` of -1)
- Focus-visible outline (ink)
- `prefers-reduced-motion` kill switch
- Empty media planes expose names via aria-label / role=img; real next/image + alt later
- Condensed mobile nav remains real links (not a fake Menu label)

### Design issue (do not silently “fix” the token)

**Muted token `#8A847A` fails WCAG AA** on Paper / Elevated / Secondary at caption sizes (~3.25:1 and lower; need 4.5:1).

**Implementation response (not a redesign):**

- Readable captions / meta use atlas-body
- Muted reserved for decorative contexts after design review
- Placeholder image annotation text from Figma was **not** painted on secondary planes (see intentional differences) because muted-on-secondary fails axe even inside aria-hidden

**Requires design review:** darken Muted, or restrict Muted to large/bold, or accept Body for all small captions in Brand System docs.

## Architecture observations

1. **Fixture shape works.** Section props take typed slices of `HomepageFixture`. Strapi mappers should target this type, not reinvent props.
2. **Rule of Two held.** No premature `ui/` package or section registry.
3. **Client JS ≈ zero.** No `"use client"` on homepage path.
4. **Tokens in one file** (`globals.css`) is enough for M0/M1; split `tokens.css` when Brand System docs need a second consumer.
5. **Layout owns chrome; page owns sections.** Correct boundary for static homepage.
6. **Manifest `app/(site)/` is fine later** — not required to validate homepage.

---

## Lessons learned

1. Frozen muted color conflicts with WCAG AA at caption size — catch early with axe in the pilot, not at launch.
2. Design annotation text on image placeholders is not production content; empty planes + captions scale better.
3. Playwright `webServer: build && start` keeps visual baselines on production CSS.
4. Including the Writing strip avoided silent design drift against Page 15.
5. Condensed mobile nav as real links beats a hamburger that isn’t designed yet.
