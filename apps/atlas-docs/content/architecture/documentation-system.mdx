## Documentation IA decision

Documentation remains a **category-driven evergreen handbook**, distinct from Articles chronology.

| Surface | Model |
| --- | --- |
| `/docs` | Purpose + categories + freshness list + search filter |
| `/docs/[…slug]` | Technical document with TOC, body, related, adjacent nav |
| Primary site nav | Unchanged (Work / About / Contact / Articles) — Docs discovered via handbook + cross-links |
| Handbook order | `docSummaries` array (drives prev/next) |
| Freshness | `docsByUpdatedDesc()` on landing |

No three-column SaaS docs portal. No Nextra clone. No card-wall redesign.
