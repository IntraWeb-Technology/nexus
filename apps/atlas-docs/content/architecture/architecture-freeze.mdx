1. Extracted `CaseStudyFixture` and related types to `src/content/case-study.ts`.
2. Moved slug registry to `src/content/case-studies/index.ts`; `portfolio-os.ts` is data-only.
3. Pointed case sections + `ArchitectureDiagram` at domain types (not the fixture file).
4. Aligned Case Study landmark model with Home/Work (`main` + nested `article`).

No redesigns, no new dependencies, no speculative abstractions, no Strapi connection.
