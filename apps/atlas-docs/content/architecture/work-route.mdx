## Accessibility report

**Target:** WCAG AA  
**Automated:** `@axe-core/playwright` — no serious/critical on `/work`

Implemented:

- Semantic landmarks and heading hierarchy (one H1)
- Skip link + focusable main
- Route-aware `aria-current` (desktop + mobile condensed)
- Empty ink / secondary media planes with `aria-label` (same AA strategy as homepage)
- Readable meta / captions use `atlas-body` (not `atlas-muted`)

### Design issues (documented — not redesigned)

1. **Muted token AA** — unchanged from homepage pilot. Figma uses `#8A847A` for meta, captions, taxonomy descriptions, contact body on ink. Implementation continues to prefer `atlas-body` / `atlas-secondary` for readable text.
2. **CONTACT chapter on ink** — Figma paints umber on ink (fails contrast). Implementation uses `atlas-secondary` (same as homepage contact).
3. **Featured UI mock annotations** — Figma includes panel chrome + status copy inside the ink figure. Implementation uses empty ink plane + accessible name (homepage media-annotation precedent).

## Lessons learned

1. **Homepage architecture scales** when sections stay page-local and chrome/editorial primitives stay thin.
2. **Rule of Stability matters** — extracting ContactBridge before compositions matched caused homepage visual drift; revert was correct.
3. **Responsive Work is not stacked desktop** — tablet/mobile drop stage rules, editorial note, theme chips, and unequal media alignments; fixture stores condensed copy.
4. **One client island is enough** for route-aware nav; the rest of `/work` stays RSC.
5. **Project fixture shape is ready for Strapi** — keep mappers at the boundary; do not let DTOs into sections.
