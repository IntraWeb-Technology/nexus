## I. TypeScript / Mapper Contract

### Boundary (mandatory)

```text
Strapi REST response
  → @repo/strapi-client (Zod validate + shape*)
  → apps/atlas-web/src/lib/strapi/* (Atlas assemblers)
  → domain types in apps/atlas-web/src/content/*.ts
  → section / editorial components
```

**Forbidden:** importing Strapi DTOs into `components/**`.
