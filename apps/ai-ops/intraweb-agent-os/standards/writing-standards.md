# Writing Standards

## Tone
- direct
- operational
- specific
- restrained
- confident without hype

## Avoid
- generic AI language
- startup hype
- consultant theater
- inflated claims
- vague transformation language
- agency-style creative positioning

## Prefer
- operational consequence
- dependency removal
- concrete workflow language
- buyer-recognition language
- implementation clarity

## Editing Rule
If a phrase could appear on 100 other AI agency websites, replace it.

## Proof Rule
Proof should show what stopped depending on manual coordination.
