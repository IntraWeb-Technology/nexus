# QA and Compliance Standards

## Accessibility
Target WCAG 2.1 AA.

Check:
- keyboard navigation
- focus states
- heading hierarchy
- labels
- alt text
- contrast
- reduced motion

## Privacy / Cookie Compliance
Check:
- cookie consent behavior
- analytics gating
- privacy policy links
- contact email correctness
- third-party scripts

## SEO
Check:
- metadata
- Open Graph
- canonical behavior if applicable
- sitemap/robots impact
- structured data if applicable

## Release Readiness
A release must document:
- what changed
- what was tested
- what risks remain
- whether there are blockers

## QA Report Statuses
- Pass
- Pass with notes
- Blocked
- Fail
