# SYS-015 — HubSpot client intake brief (batch PDF)

Batch-generate **styled PDF intake briefs** from HubSpot contacts that have **`website_intake_goals`** set, using **Python** and **ReportLab**. Real-time contact creation continues to use n8n **SYS 01.5** (markdown); this tool is for **full portfolio exports** and **PDF** output.

## Prerequisites

- Python 3.11+
- `pip install -r requirements.txt`
- HubSpot **private app** token with `crm.objects.contacts.read` (and CRM search). Set **`HUBSPOT_PRIVATE_APP_TOKEN`** or **`HUBSPOT_ACCESS_TOKEN`** in the environment.

## HubSpot search

Search **all** contacts where **`website_intake_goals`** is populated (not tied to create date). Uses CRM v3 search with pagination.

### Properties to retrieve

- `firstname`, `lastname`, `email`, `company`, `phone`, `website`
- `hs_lead_status`, `createdate`
- `website_intake_goals`, `website_intake_industry`, `website_intake_timeline`, `website_intake_pages`, `website_intake_competitors`, `website_intake_design_notes`
- `hs_object_id` (for the meta grid)

**Implementation note:** The script also requests **`website_intake_budget_range`**, **`website_intake_has_logo`**, and **`website_intake_goal_detail`** when present in the portal so **Section 6 (red flags)** can evaluate budget and brand assets. If those properties are not synced, related flags may not appear.

## PDF sections (required layout)

### Section 1 — Header banner

Slate background. **Left:** “Client Intake Brief” (large, white) + “IntraWeb Technologies · Generated [date]” (small, teal-tinted). **Right:** lead status badge (e.g. `NEW LEAD`) in a rounded slate-mid box.

### Section 2 — Contact meta grid

3×4 grid (light gray background, subtle borders):

`NAME` | value | `COMPANY` | value  
`EMAIL` | value | `PHONE` | value  
`SUBMITTED` | createdate (formatted) | `HUBSPOT ID` | `hs_object_id`

### Section 3 — Project summary

Teal divider + heading. 2–3 paragraphs: goals, industry, inspiration/competitors, scope. Call out missing information.

### Section 4 — Intake details

Two-column label/value rows (bottom border only): Industry, Goals, Timeline, Competitors / Inspiration, Design Notes.

### Section 5 — Page-by-page scope breakdown

**Include only if** `website_intake_pages` is populated. Table: **PAGE | COMPLEXITY | NOTES**. Complexity colors: **High** red (custom dev/integration), **Medium** amber (template + custom content), **Low** green (standard component), plus legend.

**Complexity rules**

- **High:** Home, Blog/Resources, Booking/Scheduling  
- **Medium:** About, Services, Pricing, Portfolio, Testimonials  
- **Low:** Contact, FAQs, Legal  

Unmatched page names default to **Medium**.

### Section 6 — Red flags / gaps

Severity cards: **HIGH** (red), **MEDIUM** (amber), **LOW** (green). Check: missing budget, unknown company/niche, vague design notes, flexible timeline risk, expectation gap vs competitors, missing brand assets, industry **Other**.

### Section 7 — Discovery call questions

**Only for non-test leads** (see test-data rule). Four groups × 3 questions: Offer Clarity; Design & Brand; Technical & Integrations; Timeline & Budget. Questions reflect gaps for this contact.

### Section 8 — Budget estimate & recommended tier

Teal badge + teal-light panel. Pricing table:

| Tier    | Setup | At go-live | Monthly retainer | Total (yr 1) |
|---------|-------|------------|------------------|--------------|
| Starter | $1,000 | $1,500 | $300/mo | ~$6,100 |
| Growth  | $2,000 | $2,000 | $450/mo | ~$9,400 |
| Ops     | Custom | Custom | Custom | Custom |

Highlight recommended row (teal-light). Footnote explains recommendation.

**Tier logic**

- **Starter:** 1–4 pages and basic lead gen (no booking/ecommerce signals).  
- **Growth:** 5–10 pages **or** booking/ecommerce.  
- **Ops:** 10+ pages **and** (custom integrations **or** weak/unknown brand identity), or strong Ops signals in goals.

### Section 9 — Recommended next steps

5–6 numbered steps (teal circles): booking invite (cite intake), lead score / ElevenLabs trigger, discovery call (cite Section 7), tier + competitor alignment, proposal via n8n PDF pipeline, HubSpot stage update.

### Section 10 — Footer

Thin border, centered:  
`IntraWeb Technologies LLC · intrawebtech.com · human@intrawebtech.com · Generated by IntraWeb OS — SYS-015 Client Intake Brief`

## Test data

If **company**, **competitors**, **design notes**, and **website** all look like obvious placeholders (e.g. `test`, `asdasd`, `xxx`) or mutual junk, mark **TEST DATA** at the top and emit a **minimal** brief; still save the PDF and list it in the summary.

## Output files

Save each PDF as **`[company-slug]-intake-brief.pdf`** under:

`E:\IntraWeb-Technologies\04_Clients\Client Briefs\`

Override with env **`CLIENT_BRIEFS_DIR`**. If company is missing or `UNKNOWN`, slug = **`firstname-lastname`** (slugified: lowercase, spaces → hyphens, strip specials).

## Run

```bash
cd tools/sys015-hubspot-intake-brief-pdf
pip install -r requirements.txt
set HUBSPOT_PRIVATE_APP_TOKEN=your_token
python generate_intake_briefs.py
```

Dry run (no HubSpot; writes one fixture PDF):

```bash
python generate_intake_briefs.py --dry-run
```
